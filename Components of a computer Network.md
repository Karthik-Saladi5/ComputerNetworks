## Components of a computer network
1. Nodes
2. Media
3. Service
   
### 1.Nodes

    Nodes are which can send or recieve or both of data

They can be Two Types:

1. End Nodes
2. Intermediary nodes

#### a) End Nodes:

These are the nodes which can be starting of the communication or ending of the comunication

Eg: Computers, printers, VoIP Phones, Security cameras


### b) Intermediary Nodes

They are the nodes which acts as bridges between two nodes

Eg: Switches , Bridges, Hubs, Routers, Repeaters

### 2. Media
    Link which is going to carry the data from side to another.

These are two types:

1. Wired Medium (Guided Medium)
    
    eg: Ethernet, fibre optic cable
2. Wireless Medium (Unguided Medium)
   
   eg: Infrared, Radio , Microwaves, Satellite

### 3. Services:

Eg: e-Mail, Storage services, file sharing
